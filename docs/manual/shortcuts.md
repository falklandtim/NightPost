# Keyboard shortcuts

Press `?` in NightPost to see this list; it's also in Preferences → Shortcuts. On Linux, use **Ctrl** wherever it says ⌘.

## Conversations

| Key | Does |
|---|---|
| `c` | New message |
| `r` | Reply |
| `a` | Reply all |
| `f` | Forward |
| `e` | Archive |
| `#` or Delete | Move to Trash |
| `!` | Report as spam |
| `b` or `h` | Snooze |
| `s` | Star or unstar |
| `u` | Mark unread |
| `p` | Pin to top, or unpin |
| `v` | Move to a folder (type its name, ↑ ↓, Return) |
| `l` | Label, on Gmail (type its name, ↑ ↓, Return) |

## Moving around

| Key | Does |
|---|---|
| `j` or ↓ | Next conversation |
| `k` or ↑ | Previous conversation |
| `g` then `i` | Go to the Inbox |
| `g` then `s` | Go to Starred |
| `g` then `t` | Go to Sent |
| `g` then `d` | Go to Drafts |
| `g` then `z` | Go to Snoozed |
| ⌘ F or `/` | Search |
| Esc | Close, clear the search, or clear the selection |

## Selecting

| Key | Does |
|---|---|
| ⌘-click | Add a conversation to the selection, or take it out |
| Shift-click | Select a range |
| Shift ↓ or Shift ↑ | Extend the selection |
| ⌘ A | Select every conversation in the list |

## Everywhere

| Key | Does |
|---|---|
| ⌘ Z | Undo (sending, moving, archiving, trashing, labels, snooze, pins…) |
| ⌘ , | Preferences |
| ⌘ Shift L | Sync activity |
| `?` | Show the shortcuts |

In a menu, ↑ ↓ choose, Return picks (or opens a submenu), and Esc closes it.

## In the message window

| Key | Does |
|---|---|
| ⌘ Return | Send |
| ⌘ S | Save the draft now |
| ⌘ K | Add a link |
| ⌘ W | Close the window (the message stays in Drafts) |
