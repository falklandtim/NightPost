# The NightPost manual

NightPost is an email client for Gmail, iCloud and any other IMAP account. It runs on the Mac and on Linux. This manual explains how to use it. For how it's built, see [the project README](../../README.md) and [AGENTS.md](../../AGENTS.md).

## Mac and Linux

NightPost works the same on both, with a few differences, which each page points out:

- **Shortcut keys:** where this manual says ⌘ (Command), use **Ctrl** on Linux. The shortcuts list in the app shows ⌘ on both.
- **Contacts:** on the Mac, NightPost suggests addresses and shows photos from the Contacts app. Linux has no address book for it to use, so suggestions come from your mail only.
- **Passwords** are kept in the Mac's Keychain, or on Linux in your desktop's keyring (GNOME Keyring or KDE Wallet).
- **HTML email** is drawn by WebKit on both. On Linux you can't select text in an HTML email yet.

## Trying it without an account

NightPost can show a demo mailbox with made-up accounts and mail, so you can look around first. On the welcome screen, click **Just looking? Explore NightPost with a demo mailbox**. Later you can remove the demo accounts in Preferences → Accounts.
